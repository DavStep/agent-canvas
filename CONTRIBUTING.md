# Contributing

Use an Apple silicon Mac with Node.js 24 or later. Run `npm ci` and `npm run dev` to work with the demo canvas. It uses scripted sessions, so you can reproduce UI changes without sharing account data.

Before opening a pull request, run `npm run typecheck`, `npm test` and `npm run test:e2e`. Describe the user-visible change and how you verified it. For interface changes, include a screenshot from the demo. Use invented folder names, transcripts, tokens and account details in fixtures.
